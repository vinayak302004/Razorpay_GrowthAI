# 5-Minute Demo Script

## 0:00–0:30 — Problem
Explain that merchants have product/customer data but often lack actionable, automated revenue-growth decisions.

## 0:30–1:20 — Dashboard
Show revenue, orders, conversion and AI opportunities.

## 1:20–2:20 — AI Agent
Ask: "How can I increase revenue this week?"
Show the agent analyzing products, customers and sales.

## 2:20–3:10 — Campaign
Open an opportunity, generate a campaign and show the merchant approval gate.

## 3:10–4:00 — Agentic Commerce
As a customer, ask for a product. Show recommendation, upsell/cross-sell and Razorpay Test Mode checkout.

## 4:00–4:30 — Payment + Audit
Show payment result and audit log.

## 4:30–5:00 — Failure
Demonstrate an API/payment failure, show that no duplicate charge occurs, then show retry/fallback and audit logging.
